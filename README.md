# 🤖 AI-HelpDesk

Sistema de **Help Desk desenvolvido em Java com Spring Boot e Spring AI**, integrado à API do **Google Gemini** para analisar chamados e sugerir níveis de prioridade com inteligência artificial.

## 🚀 Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Spring Boot** — estrutura principal da aplicação.
- **Spring AI** — integração com modelos de inteligência artificial.
- **Google Gemini** — análise dos chamados e definição de prioridades.
- **Spring Data JPA** — persistência e gerenciamento de dados.
- **Hibernate** — implementação do ORM para mapeamento objeto-relacional.
- **Banco de dados relacional** — armazenamento dos chamados.

## ⚙️ Funcionalidades

- Cadastro e gerenciamento de chamados.
- Persistência de dados com Spring Data JPA.
- Análise de chamados utilizando IA generativa.
- Classificação automática de prioridade com o Google Gemini.

## 🎯 Objetivo

Desenvolver uma aplicação de help desk que utilize inteligência artificial para auxiliar na triagem de chamados, otimizando a identificação de prioridades e tornando o processo de atendimento mais eficiente.
